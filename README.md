# Skille Claude Code

Osobiste skille do Claude Code (folder `~/.claude/skills`).

| Skill | Do czego |
|---|---|
| `materialy-szkolne` | Gotowe prompty do ChatGPT (obrazy) na ilustrowane karty pracy, notatki, wersje z lukami i gry z matematyki/fizyki/chemii, klucze odpowiedzi i korekta wygenerowanych obrazów. Folder `wzory/` zawiera obrazy wzorcowe do dołączania w ChatGPT. |
| `ms-learn-exam-tutorial` | Tutoriale przygotowujące do egzaminów Microsoft/GitHub na podstawie modułów Microsoft Learn. |

## Instalacja na innym komputerze

```
git clone https://github.com/robertkawanet/claude-skills.git %USERPROFILE%\.claude\skills
```

Jeśli folder `skills` już istnieje, sklonuj obok i skopiuj podfoldery skilli do `%USERPROFILE%\.claude\skills`.
